1.课堂的空间
课堂空间对尖子生不是“占满”，而是“精准占用”。
2.自习的空间
自习空间的质量，取决于“有多少时间是在做自己主动选择的事”
3.家庭的空间
家庭空间对尖子生的价值，是“减少干扰”而非“增加投入”。
4.活动的空间
活动空间对尖子生的意义，不是“多一个赛道”，而是“多一个确认自己是谁的镜子”。
这四个空间其实对应四种关系：

| 空间  | 核心关系      | 尖子生占住的东西 |
| --- | --------- | -------- |
| 课堂  | 与知识权威的关系  | 对话权与校准权  |
| 自习  | 与时间的关系    | 自主调度权    |
| 家庭  | 与支持系统的关系  | 低摩擦的后方   |
| 活动  | 与自我多面性的关系 | 非学术的胜任感  |

尖子生之所以“尖”，不在于他们在每个空间里都投入最多时间，而在于他们**在四个空间之间保持了低内耗的切换**——课堂不因已会而傲慢，自习不因自主而散漫，家庭不因期待而紧绷，活动不因功利而枯竭。这四个空间共同构成的，是一个**允许他们按自己的节奏深潜、又随时能浮上来换气**的生态。
