$\vec{a}=(a_1,b_1,c_1),\vec{b}=(a_2,b_2,c_2)$
设$\vec{n}=(x,y,z),\vec{n}\perp\vec{a},\vec{n}\perp\vec{b}$
$\begin{cases}a_1x+b_1y+c_1z=0\cdots①\\a_2x+b_2y+c_2z=0\cdots②\end{cases}$
$①\times c_2-②\times c_1$得
$(a_1c_2-a_2c_1)x+(b_1c_2-b_2c_1)y=0$

取$x=b_1c_2-b_2c_1,$则$y=c_1a_2-c_2a_1$
$z=a_1b_2-a_2b_1$
所以法向量可取为$\vec{n}=(b_1c_2-b_2c_1,c_1a_2-c_2a_1,a_1b_2-a_2b_1)$

【补充】
向量叉乘的定义

$\vec{a}\times\vec{b}=\begin{vmatrix}\vec{i}\ \ \  \vec{j}\ \ \ \vec{k}\\a_1 \ \ b_1\ \  c_1\\a_2 \ \ b_2 \ \ c_2\end{vmatrix}=(b_1c_2-b_2c_1,c_1a_2-c_2a_1,a_1b_2-a_2b_1)$
