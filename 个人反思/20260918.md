## 一、全框架通关：从定义出发画知识树

**核心原则：** 不翻书、不提示，先默写框架，再对照补漏。

**操作步骤：**

1. **选章节**：以一章为单位，拿出一张白纸。
2. **默写三层结构**：
   - **第一层：核心定义**（这一章到底在研究什么对象？）
   - **第二层：性质与公式**（由定义直接推出的结论）
   - **第三层：解题方法与适用条件**（什么题型用什么工具）
3. **标注易错点**：每个公式旁边用红笔写“使用前提”和“常见陷阱”。
4. **对照教材/笔记**：用不同颜色补上遗漏，形成最终版知识树。

**示例：以“导数”一章为例**

```
导数
├── 定义
│   ├── 平均变化率 → 瞬时变化率（极限）
│   ├── 几何意义：切线斜率
│   └── 物理意义：瞬时速度
├── 运算
│   ├── 基本公式表（幂、指、对、三角）
│   ├── 四则运算
│   ├── 复合函数链式法则
│   └── 隐函数/参数方程求导
├── 应用
│   ├── 单调性（f' > 0 / < 0）
│   ├── 极值（f' = 0 且变号）
│   ├── 最值（闭区间 vs 开区间）
│   └── 切线方程（在某点 vs 过某点）
└── 易错点
    ├── f'(x₀) 存在 ≠ 在该点连续（可导必连续，连续不一定可导）
    ├── 极值点不一定是 f' = 0 的点（如 x³ 在 0 处）
    └── “过某点”切线需设切点，不能直接代入
```

**检验标准：** 合上纸，能对着空白纸把整棵树复述出来，才算通关。

## 二、全逻辑重走：错题四问拆解法

**核心原则：** 盖住解析，独立拆解，把“做对”变成“讲清”。

**四个问题固定顺序：**

| 问题 | 具体追问 | 记录方式 |
|------|----------|----------|
| 1. 核心考点是什么？ | 这道题在考哪个定义/公式/方法？ | 用一句话写标题 |
| 2. 破题关键条件是哪一处？ | 哪个条件让思路拐弯？ | 圈出题干关键词 |
| 3. 解题分几步？每步依据？ | 每步写“因为…所以…” | 分步编号，注明定理 |
| 4. 最易错节点？后果？ | 哪步容易算错/想漏？ | 红笔写“若错→…” |

**示例：一道导数切线题**

> 题目：求曲线 y = x³ - 2x 过点 (1, -1) 的切线方程。

- **核心考点**：导数几何意义 + “过点”切线设切点
- **关键条件**：“过点”不是“在点”，(1, -1) 不一定在曲线上
- **步骤**：
  1. 设切点 (t, t³ - 2t) —— 依据：切线斜率需用切点导数
  2. 斜率 k = 3t² - 2 —— 依据：f'(t) 几何意义
  3. 切线方程 y - (t³ - 2t) = (3t² - 2)(x - t) —— 依据：点斜式
  4. 代入 (1, -1) 解 t —— 依据：点在切线上
  5. 回代得切线 —— 依据：每个 t 对应一条切线
- **易错节点**：直接认为 (1, -1) 是切点 → 漏解或错解

**执行要求：** 每道错题必须能不看解析，把这四问答出来。答不出，说明没真懂。

## 三、每周漏洞清零：固定复盘机制

**核心原则：** 集中时间、集中处理、集中销毁。

**建议流程（每周 1 次，60–90 分钟）：**

1. **收集**：本周所有卡壳题、错题、默写漏点，统一编号。
2. **分类**：
   - A 类：概念不清（定义记错、条件漏看）
   - B 类：方法不熟（知道考什么但不会下手）
   - C 类：计算失误（思路对但算错）
3. **清零**：
   - A 类 → 回到框架树，补定义和适用条件
   - B 类 → 重走四问，整理成“题型—方法”卡片
   - C 类 → 单独抄写易错计算步骤，限时重算 3 遍
4. **验收**：随机抽 3 道本周错题，盖住解析独立做，全对才算清零。
5. **归档**：把已清零的题标记日期，两周后再抽一次，防止假性掌握。

**工具建议：**
- 一个本子分三栏：日期 | 漏洞描述 | 清零日期
- 每周末统计：A/B/C 类各多少，哪类反复出现

