下面是一份专门针对“逃避漏洞、在舒适区里努力”这个问题的执行表。设计原则是：**不靠意志力，靠结构；不要求爱上弱科，只要求不逃它。**

---

## 一、核心结构：每周只攻一个漏洞

整张表围绕一个循环：

> **定位漏洞 → 拆成最小行动 → 每天执行 → 记录证据 → 周末验收**

关键约束：
- 一周只选**一个**漏洞，不贪多
- 每天只做**15—30分钟**针对性行动
- 记录的是**行动证据**，不是分数
- 周末只问一个问题：**这个漏洞还在吗？**

| 周六  |        | ✅ / ❌ |       |        |

**“今日最小行动”写法示例：**
- 做1道圆锥曲线中档题，完整写出“设直线→联立→韦达定理”三步
- 重做昨天错题1道，遮住答案独立完成
- 默写错位相减的完整步骤，再套1道题
- 精读1篇英语阅读，只分析主旨题为什么选错

**“卡在哪一步”是关键栏。** 它把“我不会”变成“我卡在具体哪一步”，漏洞就从模糊的恐惧变成可解决的问题。

### 周末验收表

| 验收问题 | 回答 |
|---|---|
| 本周这个漏洞，我碰了几次？ | |
| 有没有一道题，我周一不会、现在会了？ | |
| 这个漏洞是消失了、变小了、还是没变？ | |
| 如果没变，是行动不对，还是行动不够？ | |
| 下周继续攻这个漏洞，还是换一个？ | |

**验收标准不是“分数涨了”，而是：**
- 能独立做出一道之前不会的题
- 能讲清楚这类题的第一步
- 错题本上这类题不再重复错

| 学科 | 最近一次考试丢分最多的题型 | 丢分原因（A概念不清/B算错/C不会） | 下周是否主攻 |
|---|---|---|---|
| 数学 | | | |
| 物理 | | | |
| 英语 | | | |
| 其他 | | | |

**选择规则：**
1. 优先选 **B类（思路有但算错/步骤丢分）** ——提分最快
2. 其次选 **A类（概念不清）** 中你觉得“其实能学懂”的
3. 一次只选一个，不要同时攻三科

## 四、防逃避机制（这张表最关键的部分）

逃避漏洞的学生，最容易在这几个环节溜走。对应设计：

| 逃避方式 | 防逃避设计 |
|---|---|
| “我今天太忙了，明天补” | 最小行动只要15分钟，忙不是理由 |
| “我做了但没效果” | 记录“卡在哪一步”，效果看的是这一步有没有推进 |
| “这题我还是不会” | 不问“会不会”，问“卡在哪”，卡点就是进步点 |
| “我换一科攻吧” | 一周只能换一次，周末验收后才决定 |
| “我不好意思问老师” | 允许先问同学、先写下来、先自己查，但必须留下记录 |
| “我做了很多题” | 只认“不会的题变会了”，不认“做了多少题” |

## 六、使用说明（给学生）

1. **每周日晚上花10分钟**，填“漏洞定位表”，选出下周唯一漏洞。
2. **每天开始前**，写下今天的最小行动，越具体越好。
3. **做完立刻记录**，不要攒到周末补。
4. **“卡在哪一步”必须写**，哪怕写“我连第一步都不知道”。
5. **周末验收只看一件事**：有没有一道题，从不会变会了。
6. **如果一周没效果，不要换方法，先问：我真的每天碰它了吗？**

---

## 七、使用说明（给老师/家长）

- 不要问“今天学了吗”，问“今天碰了哪个不会的题”
- 不要夸“真刻苦”，夸“你今天敢碰那道难题了”
- 不要盯着分数，盯着“卡点有没有变化”
- 如果学生说“我做了但没效果”，让他拿出这张表，看“卡在哪一步”那一栏是不是空的

---

## 八、一句话总结

> **这张表不要求你变自律，只要求你每天碰一下那个你不会的东西。**
> **碰着碰着，漏洞就小了；漏洞小了，成绩就上来了。**
