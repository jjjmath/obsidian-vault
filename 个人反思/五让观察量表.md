## 使用说明

- 每项按 **0—3 分** 打分：  
  **0 = 未发生｜1 = 形式化｜2 = 基本发生｜3 = 充分发生**
- 重点看**学生行为**，不只看教师设计。
- 每项至少记一条**关键证据**（原话、动作、场景）。

## 一、让阅读发生

| 观察点 | 0 | 1 | 2 | 3 | 关键证据 |
|---|---|---|---|---|---|
| 学生有独立阅读数学文本的时间 |  |  |  |  |  |
| 阅读有明确任务（圈词、标疑、找条件结论） |  |  |  |  |  |

**典型场景：** 默读定义、读长题干、对比阅读、圈画条件结论。

## 二、让提问发生

| 观察点 | 0 | 1 | 2 | 3 | 关键证据 |
|---|---|---|---|---|---|
| 学生提出真问题（非“对不对”“是不是”） |  |  |  |  |  |
| 问题指向条件、依据、反例或方法差异 |  |  |  |  |  |
| 教师不急于回答，把问题还给学生 |  |  |  |  |  |

**典型场景：** “如果改成任意呢？”“这一步凭什么？”“反过来成立吗？”  
**流于形式的表现：** 只有教师问、学生答；问题全是记忆性、判断性。

**本节得分：**____ / 9

## 三、让合作发生

| 观察点 | 0 | 1 | 2 | 3 | 关键证据 |
|---|---|---|---|---|---|
| 合作有需要多人完成的任务 |  |  |  |  |  |
| 人人有角色、有发言、有记录 |  |  |  |  |  |
| 出现质疑、比较、统一结论的过程 |  |  |  |  |  |

**典型场景：** 一题多解比较、错解辨析、开放题分工、互查互评。  
**流于形式的表现：** 只是同桌对答案；好学生讲，其他人抄；无角色、无产出。

## 四、让展示发生

| 观察点 | 0 | 1 | 2 | 3 | 关键证据 |
|---|---|---|---|---|---|
| 学生公开展示思维过程，不只报答案 |  |  |  |  |  |
| 展示者讲清“怎么想到的”“哪步易错” |  |  |  |  |  |
| 台下有提问、评价或追问 |  |  |  |  |  |

**典型场景：** 上台讲题、投影原始过程、错解展示、知识结构汇报。  
**流于形式的表现：** 只让个别学生板书答案；台下无事可做；无质疑环节。
