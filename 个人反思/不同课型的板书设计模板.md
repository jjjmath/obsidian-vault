# 不同课型的板书模板

下面按**新授课、习题课、复习课、讲评课、概念课、实验/探究课**六种常见课型，给出可直接套用的板书模板。每个模板都包含：**分区布局、各区域功能、书写节奏、配合语言**。

---

## 模板一：新授课板书模板

**适用：** 第一次讲某个概念、定理、公式、法则。

### 布局

```
┌─────────────────────────────────────────────────────────────┐
│  课题：___________________________    日期：___________      │
├───────────────────────────────┬─────────────────────────────┤
│                               │                             │
│        主板书区                │       方法/步骤区            │
│   （例题完整演算过程）          │   （步骤、依据、关键词）      │
│                               │                             │
│                               ├─────────────────────────────┤
│                               │                             │
│                               │       易错/对比区            │
│                               │   （常见错误、正确对比）      │
│                               │                             │
├───────────────────────────────┴─────────────────────────────┤
│                      小结/留白区                              │
│   （学生补充、课堂生成、重点回扣）                             │
└─────────────────────────────────────────────────────────────┘
```

### 各区域功能

| 区域 | 写什么 | 什么时候写 |
|------|--------|------------|
| 主板书区 | 例题从条件到结论的完整过程 | 讲解时同步写 |
| 方法/步骤区 | 解题步骤、定理关键词、依据 | 例题讲完后提炼 |
| 易错/对比区 | 学生易错点、错误 vs 正确 | 讲到关键处随手写 |
| 小结/留白区 | 一句话总结、学生补充 | 课尾 |

### 书写节奏

- 主板书区：**写一步 → 停 → 讲一句 → 再写下一步**
- 方法区：例题讲完后**回指主板书**，逐条提炼
- 易错区：发现学生错误时**当场写**，不等到最后
- 小结区：**让学生说**，教师选择性写

### 配合语言示例

> “大家看这一步，我为什么要两边同乘6？因为……（写）”
> “现在我把这个方法提炼一下，大家看黑板右边——（写）”
> “这里容易错，我把它写在旁边，大家记一下——（写）”

## 模板二：习题课板书模板

**适用：** 讲解多道题，训练解题能力，总结题型方法。

### 布局

```
┌─────────────────────────────────────────────────────────────┐
│  课题：___________________________    日期：___________      │
├───────────────────────────────┬─────────────────────────────┤
│                               │                             │
│      例题1完整演算             │      题型模型区              │
│                               │                             │
│                               │   题型特征：__________       │
│                               │   解题步骤：__________       │
│                               │   关键点：____________       │
│                               ├─────────────────────────────┤
│      例题2完整演算             │                             │
│                               │      变式/拓展区             │
│                               │                             │
│                               │   变式1：__________          │
│                               │   变式2：__________          │
│                               │                             │
├───────────────────────────────┴─────────────────────────────┤
│                      易错归纳区                              │
│   （本课多道题共同易错点，用彩色粉笔标出）                     │
└─────────────────────────────────────────────────────────────┘
```

### 各区域功能

| 区域 | 写什么 | 什么时候写 |
|------|--------|------------|
| 例题区 | 每道题完整过程，不跳步 | 逐题讲解时写 |
| 题型模型区 | 该题型的通用解法、步骤 | 每道题讲完后提炼 |
| 变式/拓展区 | 条件变化后的思路 | 学生掌握基础后拓展 |
| 易错归纳区 | 多题共同易错点 | 课尾集中归纳 |

### 书写节奏

- 例题1：**完整写 → 提炼模型 → 写进模型区**
- 例题2：**完整写 → 与例题1对比 → 补充模型区**
- 变式：**只写关键变化，不重复完整过程**
- 易错区：**课尾回指前面例题，集中写**

### 关键原则

> **例题不跳步，变式可省略。**
> 第一道题是“示范”，必须完整；后面同类型题可以只写关键步骤。

## 模板三：复习课板书模板

**适用：** 单元复习、期中期末复习、专题复习。

### 布局（思维导图式）

```
┌─────────────────────────────────────────────────────────────┐
│  课题：___________________________    日期：___________      │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│                        ┌─────────┐                          │
│                        │ 核心概念 │                          │
│                        └────┬────┘                          │
│              ┌──────────────┼──────────────┐                │
│              │              │              │                │
│         ┌────┴────┐    ┌────┴────┐    ┌────┴────┐           │
│         │ 知识点1  │    │ 知识点2  │    │ 知识点3  │           │
│         └────┬────┘    └────┬────┘    └────┬────┘           │
│              │              │              │                │
│         典型题/易错      典型题/易错      典型题/易错          │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│                      综合应用区                              │
│   （一道综合题，串联多个知识点，完整演算）                     │
├─────────────────────────────────────────────────────────────┤
│                      学生留白区                              │
│   （让学生自己补充知识网络、易错点、疑问）                     │
└─────────────────────────────────────────────────────────────┘
```

### 各区域功能

| 区域 | 写什么 | 什么时候写 |
|------|--------|------------|
| 思维导图区 | 知识结构、概念关系 | 边问边写，学生说教师写 |
| 典型题/易错 | 每个知识点下的代表题、易错点 | 讲到该知识点时写 |
| 综合应用区 | 一道串联多知识点的综合题 | 复习后半段 |
| 学生留白区 | 学生自己补充 | 课尾或课后 |

### 书写节奏

- 思维导图：**不要一次画完**，讲一块画一块，最后连成整体
- 典型题：**只写关键步骤和易错点**，不重复新授课的完整演算
- 综合题：**完整写**，因为这是检验复习效果的关键
- 留白区：**让学生上来写**，教师点评

### 关键原则

> **复习课板书是“压缩包”，不是“重新解压”。**
> 新授课是展开，复习课是结构化。但综合题仍要完整。

## 模板四：试卷讲评课板书模板

**适用：** 考试后讲评试卷，分析错误，提炼方法。

### 布局

```
┌─────────────────────────────────────────────────────────────┐
│  课题：________试卷讲评        日期：___________            │
├───────────────────────────────┬─────────────────────────────┤
│                               │                             │
│      重点题完整演算            │      错误统计区              │
│   （选取错误率最高的2-3题）     │                             │
│                               │   题号 | 错误率 | 错因       │
│                               │   ____ | ______ | ______    │
│                               │   ____ | ______ | ______    │
│                               │                             │
│                               ├─────────────────────────────┤
│                               │                             │
│                               │      方法提炼区              │
│                               │                             │
│                               │   本题型通用解法：______     │
│                               │   关键步骤：__________       │
│                               │                             │
├───────────────────────────────┴─────────────────────────────┤
│                      变式训练区                              │
│   （针对错题，现场出一道变式，学生练，教师巡）                 │
└─────────────────────────────────────────────────────────────┘
```

### 各区域功能

| 区域 | 写什么 | 什么时候写 |
|------|--------|------------|
| 重点题演算 | 错误率高的题，完整正确过程 | 讲评时写 |
| 错误统计区 | 题号、错误率、典型错因 | 课前准备好数据，课上写 |
| 方法提炼区 | 该题型的通用方法 | 讲完重点题后 |
| 变式训练区 | 现场变式题 | 讲评后当堂练 |

### 书写节奏

- 错误统计：**课前写好或投影**，课上直接指
- 重点题：**先展示学生错误解法 → 分析错因 → 再写正确过程**
- 方法提炼：**回指重点题**，逐条提炼
- 变式：**留给学生时间做**，教师巡视，个别指导

### 关键原则

> **讲评课板书的核心是“对比”。**
> 错误解法 vs 正确解法，并排写，对比才深刻。

## 模板五：概念课板书模板

**适用：** 数学概念、定义的生成与理解。

### 布局

```
┌─────────────────────────────────────────────────────────────┐
│  课题：___________________________    日期：___________      │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│      概念生成区                                              │
│                                                             │
│   1. 具体实例：______________                                │
│   2. 共同特征：______________                                │
│   3. 自然语言：______________                                │
│   4. 数学符号：______________                                │
│   5. 正式定义：______________                                │
│                                                             │
├───────────────────────────────┬─────────────────────────────┤
│      关键词辨析区              │      正反例区                │
│                               │                             │
│   关键词1：__________          │   正例：__________           │
│   关键词2：__________          │   反例：__________           │
│   关键词3：__________          │                             │
│                               │                             │
├───────────────────────────────┴─────────────────────────────┤
│                      应用/辨析区                             │
│   （判断哪些符合定义，哪些不符合，说明理由）                   │
└─────────────────────────────────────────────────────────────┘
```

### 各区域功能

| 区域 | 写什么 | 什么时候写 |
|------|--------|------------|
| 概念生成区 | 从实例到定义的完整抽象过程 | 引导时逐步写 |
| 关键词辨析区 | 定义中的关键词逐字解释 | 定义给出后 |
| 正反例区 | 符合/不符合定义的例子 | 辨析时写 |
| 应用/辨析区 | 判断题、选择题 | 巩固时写 |

### 书写节奏

- 概念生成：**不要直接给定义**，一步一步引导，每一步都写
- 关键词：**用彩色粉笔圈出**，逐字解释
- 正反例：**让学生判断**，教师写
- 辨析：**学生说理由**，教师板书关键判断依据

### 关键原则

> **概念课板书的核心是“慢”。**
> 定义给出的过程越慢，学生理解越深。关键词要逐字抠。

## 模板六：探究/实验课板书模板

**适用：** 数学探究活动、动手操作、发现规律。

```
┌─────────────────────────────────────────────────────────────┐

├─────────────────────────────────────────────────────────────┤
│                                                             │
│      探究过程区                                              │
│                                                             │
│   1. 提出问题：______________                                │
│   2. 动手操作：______________                                │
│   3. 观察记录：______________                                │
│   4. 猜想：__________________                                │
│   5. 验证：__________________                                │
│   6. 结论：__________________                                │
│                                                             │
├───────────────────────────────┬─────────────────────────────┤
│      数据/现象记录区           │      规律提炼区              │
│                               │                             │
│   小组1：__________            │   共同规律：__________       │
│   小组2：__________            │   数学表达：__________       │
│   小组3：__________            │                             │
│                               │                             │
├───────────────────────────────┴─────────────────────────────┤
│                      证明/说理区                             │
│   （从猜想走向证明，完整逻辑链）                               │
└─────────────────────────────────────────────────────────────┘
```

### 各区域功能

| 区域 | 写什么 | 什么时候写 |
|------|--------|------------|
| 探究过程区 | 问题→操作→观察→猜想→验证→结论 | 随探究进程同步写 |
| 数据记录区 | 各小组数据 | 小组汇报时写 |
| 规律提炼区 | 从数据中提炼的共同规律 | 汇报后集体归纳 |
| 证明/说理区 | 严格证明或说理 | 最后阶段 |

### 书写节奏

- 探究过程：**边探究边写**，不要等到最后补
- 数据记录：**让学生报，教师写**，保持真实
- 规律提炼：**引导学生自己说**，教师提炼
- 证明：**完整写**，这是探究的落脚点

### 关键原则

> **探究课板书的核心是“留痕”。**
> 探究过程转瞬即逝，板书要把思维过程固定下来。

## 六种模板对比总表

| 课型 | 核心区域 | 书写重点 | 节奏关键 | 一句话原则 |
|------|----------|----------|----------|------------|
| 新授课 | 主板书+方法区 | 完整演算+步骤提炼 | 写一步停一步 | 不跳步 |
| 习题课 | 例题+模型区 | 首题完整，变式省略 | 讲一题提炼一题 | 例题示范，变式放手 |
| 复习课 | 思维导图+综合题 | 结构化+综合应用 | 边问边写 | 压缩包，不是重新解压 |
| 讲评课 | 错题+对比区 | 错误vs正确并排 | 先错后对 | 对比才深刻 |
| 概念课 | 生成区+辨析区 | 从实例到定义 | 慢，逐字抠 | 定义给出越慢越好 |
| 探究课 | 过程区+规律区 | 探究全程留痕 | 边做边写 | 把思维固定下来 |

## 通用板书口诀

> **新课不跳步，习题抓模型。**
> **复习建结构，讲评重对比。**
> **概念慢慢抠，探究步步留。**
> **分区要清楚，彩色标关键。**
> **边写边要讲，写完回头指。**
> **不轻易擦掉，小结再用它。**
