问题：直线$l$的方程为$y=x+m$,若圆$x^2+y^2-4x=0$上有且仅有$3$个点到直线$l$的距离为$1$,求$m$的值
【解析】
如图所示![[20260918001]]
当圆心到直线的距离等于$1$时满足题意
所以$$\frac{|2+m|}{\sqrt{2}}=1$$
解得$m=-2\pm\sqrt2$


**探究追问**
①如果恰有一个点到直线$l$的距离为$1$，直线斜率的取值如何？
此时需要保证的是圆上的点到直线$l$的距离的最小值为$1$
即圆心到直线的距离$d-r=1$
再改变条件，如果恰有一个点到直线的距离为$3$,则会有两种情况，一种是上述$d-r=3$
另一种是$d+r=3$
②如果恰有两个点到直线$l$的距离为$1$，直线斜率的取值如何？
$-1<d-r<1$
③如果至少有三个点到直线$l$的距离为$1$，直线斜率的取值如何？
$d<1$


| 圆上到直线距离为1的点 | 圆心到直线的距离d |
| ----------- | --------- |
| 0个          | $d>3$     |
| 1个          | $d=3$     |
| 2个          | $1<d<3$   |
| 3个          | $d=1$     |
| 4个          | $d<1$     |
| 2个          | $d=0$     |


| 圆上到直线距离为3点 | 圆心到直线的距离d   |
| ---------- | ----------- |
| 0个         | $d>5$       |
| 1个         | $d=5$或$d=1$ |
| 2个         | $1<d<5$     |
| 3个         | 不成立         |
| 4个         | 不成立         |
